# AetherDrive — быстрый прототип (тёмная тема + общий backend)

Обновлённая версия прототипа: фронтенд теперь использует backend для общего хранения файлов (shared drive). Если сервер не указан или недоступен, сайт автоматически использует локальное хранилище браузера.

Файлы в этой ветке (gh-pages):
- index.html — фронтенд (тёмная тема)
- app.js — логика с поддержкой backend
- styles.css — тёмная тема

Как подключиться к backend для общего доступа:
1. Разверните backend из ветки `main` (файлы в каталоге `backend/`) на любом хостинге (локально: `uvicorn backend.app:app --reload --host 0.0.0.0 --port 8000`).
2. В UI введите URL backend (например, `http://localhost:8000`) и нажмите «Подключиться».

Дальше — Backend (в ветке main) содержит API для загрузки, списка, скачивания и удаления файлов. См. backend/README.md для деталей развертывания.
