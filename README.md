# AetherDrive — быстрый прототип

Это простой статический прототип "аналог Google Drive" — фронтенд, который хранит файлы в браузере (localStorage). Это быстрый способ получить интерфейс загрузки, просмотра и скачивания файлов и разместить сайт через GitHub Pages.

Что в репозитории (ветка gh-pages):
- index.html — фронтенд
- app.js — логика загрузки/хранения/скачивания
- styles.css — простые стили

Как развернуть (быстро):
1. Перейдите в настройки репозитория на GitHub → Pages.
2. Выберите ветку `gh-pages` (либо ветку `gh-pages` и корень `/`) для публикации и сохраните.
3. Через пару минут сайт будет доступен по адресу `https://<ваш-логин>.github.io/aetherdrive/`.

Ограничения и дальнейшие шаги:
- Сейчас файлы сохраняются локально в браузере (не синхронизируются между устройствами).
- Для настоящего облачного хранилища нужно серверное хранилище (S3, сервер на Render/Heroku/Cloud Run или использовать GitHub как backend через API — но это требует авторизации и бэкенда).
- Можно добавить: регистрация/авторизация, хранение в облаке, просмотр изображений/превью, шаринг ссылок, папки и права доступа.
