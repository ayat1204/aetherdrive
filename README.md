# AetherDrive — frontend (gh-pages)

Фронтенд теперь требует работающий backend (S3). Локальное хранение отключено — все операции идут через API.

Как подключиться:
1. Разверните backend (branch: main) и получите публичный URL.
2. Откройте эту страницу, введите Backend URL и API Key (если требуется) и нажмите "Подключиться".
