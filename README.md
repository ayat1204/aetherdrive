# aetherdrive

Простой публичный файловый дроп (пример).

Запуск локально:

1. python -m venv venv
2. (Linux/Mac) source venv/bin/activate   # Windows: venv\\Scripts\\activate
3. pip install -r requirements.txt
4. python app.py
5. Открой http://localhost:5000

Примечание: это тестовая версия — не используйте публично без доработок: добавь лимиты, антивирус, квоты, HTTPS и хранение в облаке для продакшена.
